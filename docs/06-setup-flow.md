# 6. First-Time Setup Flow

7 steps. First screen a new client sees.

1. Access Code Gate — blocks illegal installs
2. Generate License — app calls server, server returns license + plan
3. Pricing Confirmation — one-time / rent-to-own / subscription
4. Shop Details — name, type, location, owner
5. Contact Info — phone, email
6. Admin Credentials — auto-suggested username + random password
7. Done — verifies internet before letting them in

## Rules

- Red banner: "Stay connected to the internet during installation"
- No security disclosures
- No plan chooser (client already decided at purchase)
