# 10. Design Principles

1. One app, many clients
2. No per-client hosting
3. Offline-first
4. Rust is the backend, React is UI only
5. Flexible RBAC — permissions in code, groups in DB
6. Django-style separation
7. Client owns their data
8. You own distribution (signed updates, kill switch)
9. Fail-open on your server outage
10. Ship features, not complexity
